# Roadmap execution prompt

Proceed with the next incomplete micro-phase from ROADMAP.md.

Before coding:

1. Restate the specific phase/subphase scope.
2. Identify the exact files you expect to modify.
3. Identify tests you will add or update.
4. Confirm no unrelated work will be changed.

Then implement only that scope, run validation, update ROADMAP.md with timestamp and notes, and provide the commit summary.

If a phase contains more than 8 implementation tasks or touches both frontend and backend heavily, split it into micro-phases before implementation.
